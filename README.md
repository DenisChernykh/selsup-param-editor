# Редактор параметров товара

React-компонент для редактирования параметров товара по схеме и исходной модели.

## Возможности

- Построение полей из массива параметров.
- Инициализация значений и получение полной модели.
- TypeScript-контракты и проверки на Vitest/Testing Library.

## Инженерные акценты

- Проектирование API переиспользуемого компонента.
- Согласование входной схемы и редактируемого состояния.
- Проверка поведения и сохранности модели тестами.

## Стек

React, TypeScript, Vite, Vitest.

## Навигация по коду

- [src/](src/) — исходный код.
